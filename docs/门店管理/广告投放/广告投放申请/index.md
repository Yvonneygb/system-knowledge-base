<div class="kl-wrap">
<KbCard num="1" title="重点逻辑1：申请总金额校验 提交校验">
<KbQuote>确保申请单的申请总金额有效，防止提交金额为0或负数的申请</KbQuote>

**具体逻辑**：

- 1、提交前校验申请总金额必须大于0
- 2、校验失败阻断工作流提交
</KbCard>

<KbCard num="2" title="重点逻辑2：推送OA审批 工作流节点">
<KbQuote>广告投放申请需推送OA系统进行审批，OA审批结果回调更新申请单</KbQuote>

**具体逻辑**：

- 1、查询申请单信息，校验申请单是否存在
- 2、将申请数据转换为OA表单格式，包括申请单号、经销商、广告公司、交易公司、媒介信息、金额等
- 3、额度内申请时费用类型为"额度内"，额度外为"额度外"
- 4、申请使用占比=额度内占比%并拼接%号
- 5、查询附件信息一并推送OA
- 6、额度外申请推送OA成功后，扣减超预算税总额
</KbCard>

<KbCard num="3" title="重点逻辑3：OA审批回调处理 外部回调">
<KbQuote>OA审批完成后回调更新申请单数据，保持系统数据与OA审批结果一致</KbQuote>

**具体逻辑**：

- 1、仅最终审批人审批时才处理回调数据（slHFinalApprover=Y）
- 2、审批同意时：更新广告描述、媒介类型、可用金额、申请总金额、使用占比、批准总金额、媒介说明
- 3、审批同意时计算申请占比=申请总金额÷可用金额×100（保留6位小数），批准占比=批准总金额÷可用金额×100（保留6位小数）
- 4、审批同意时设置回调来源=OA_PASS，更新工作流变量callbackSource=1
- 5、审批不同意时设置回调来源=OA_REJECT，更新工作流变量callbackSource=2
- 6、额度外申请审批不同意时，恢复之前扣减的超预算税总额
</KbCard>

<KbCard num="4" title="重点逻辑4：额度外超预算处理 OA推送/回调">
<KbQuote>额度外申请涉及超预算管理，需在推送OA前扣减预算，OA驳回时恢复</KbQuote>

**具体逻辑**：

- 1、额度外申请推送OA成功后，扣减BUD_OVER_BUDGET中对应年度、组织、费用类型(66014602)的税总额
- 2、OA审批驳回时，恢复之前扣减的税总额（加回）
</KbCard>

<KbCard num="5" title="重点逻辑5：额度外可用余额查询 独立接口">

**具体逻辑**：

- 1、校验预算年度、部门ID、费用类型ID不能为空
- 2、可用余额=可用金额-占用金额
- 3、通过queryResourceAmt接口对外提供查询
