<KbCard num="1" title="重点逻辑1：保存前多重校验 {保存校验链}">
<KbQuote>保证合同数据的完整性和合法性</KbQuote>

**具体逻辑**：

- 1、**业务意义**：保证合同数据的完整性和合法性
- 2、具体逻辑描述
- 3、第1点：合同开始日期须为月度第一天(1号)
- 4、第2点：合同结束日期不能早于开始日期
- 5、第3点：校验同经销商+同法人+同交易公司+同合同类型下是否存在时间重叠的合同
- 6、第4点：校验合同类型分组是否冲突(不同分组的合同不能在同一时间范围内共存)
- 7、第5点：校验授权区域是否与已有合同冲突(非网络经销合同不校验)
- 8、第6点：校验新开发网点月度明细之和是否等于新开发网点个数(仅特定事业部+合同类型)
</KbCard>

<KbCard num="2" title="重点逻辑2：年度营销政策自动关联 {政策匹配}">
<KbQuote>保存合同时自动匹配年度营销政策，将政策行ID写入合同头</KbQuote>

**具体逻辑**：

- 1、**业务意义**：保存合同时自动匹配年度营销政策，将政策行ID写入合同头
- 2、具体逻辑描述
- 3、第1点：根据合同的事业部+合同类型+销售年度匹配年度营销政策
- 4、第2点：匹配成功后，将返点(rebate)、违约金(breach)、次年折扣(discount)对应的政策行ID分别写入REBATE_ID、BREACH_ID、DISCOUNT_ID
</KbCard>

<KbCard num="3" title="重点逻辑3：保证金自动计算 {保证金标准}">
<KbQuote>根据事业部和合同类型自动计算保证金金额</KbQuote>

**具体逻辑**：

- 1、**业务意义**：根据事业部和合同类型自动计算保证金金额
- 2、具体逻辑描述
- 3、第1点：查询CM_DEPOSITS_PAY_STANDARD表获取保证金标准金额
- 4、第2点：保证金(万元)=标准金额/10000，保留2位小数
- 5、第3点：若标准金额为0，保证金为0；若查询不到标准，阻断保存
</KbCard>

<KbCard num="4" title="重点逻辑4：延迟发货日期自动计算 {系统配置}">
<KbQuote>根据系统配置自动计算延迟发货日期</KbQuote>

**具体逻辑**：

- 1、**业务意义**：根据系统配置自动计算延迟发货日期
- 2、具体逻辑描述
- 3、第1点：从系统配置读取Contract_Delay_Date(延迟天数)
- 4、第2点：延迟发货日期=合同结束日期+延迟天数
</KbCard>

<KbCard num="5" title="重点逻辑5：工作流审批回调 {审批流程}">
<KbQuote>审批通过后执行一系列后续操作</KbQuote>

**具体逻辑**：

- 1、**业务意义**：审批通过后执行一系列后续操作
- 2、具体逻辑描述
- 3、第1点：更新旧合同经销期限(结束日期改为新合同开始日期-1天)
- 4、第2点：推送CRM系统
- 5、第3点：生成归档日期
- 6、第4点：更新生效状态为2(生效)
- 7、第5点：同步MBO经销合同
- 8、第6点：更新审核状态为"审核通过"
- 9、--
</KbCard>

<KbCard title="保存校验">
<KbSubTitle>校验1：合同开始日期须为月度第一天 —— 保证合同按整月签订</KbSubTitle>

- 第1点：校验startDate的dayOfMonth是否为1

<KbTip>阻断性报错</KbTip>

```sql
SELECT SA_CONTR_HEAD_ID, START_DATE FROM SA_SALE_CONTRACT_HEAD WHERE EXTRACT(DAY FROM START_DATE) != 1
```

<KbSubTitle>校验2：合同结束日期不能早于开始日期 —— 保证时间区间合法</KbSubTitle>

- 第1点：校验endDate &gt;= startDate

<KbTip>阻断性报错</KbTip>

```sql
SELECT SA_CONTR_HEAD_ID, START_DATE, END_DATE FROM SA_SALE_CONTRACT_HEAD WHERE END_DATE < START_DATE
```

<KbSubTitle>校验3：同经销商同合同类型时间范围不能重叠 —— 防止重复签合同</KbSubTitle>

- 第1点：查询同经销商+同法人+同交易公司+审核状态为已提交/已送OA/审核通过/CRM驳回的合同
- 第2点：判断时间范围是否重叠
- 第3点：若合同类型分组不同，阻断保存

<KbTip>阻断性报错</KbTip>

```sql
SELECT * FROM SA_SALE_CONTRACT_HEAD 
    WHERE CUST_CODE = :custCode 
      AND CORPORATE_CODE = :corporateCode 
      AND TRADING_COMPANY_CODE = :tradingCompanyCode 
      AND SALES_CONTRACT_TYPE = :contractType
      AND AUDIT_STAT IN ('已提交', '已送OA', '审核通过', 'CRM驳回')
      AND VALID IN (1, 2)
      AND END_DATE >= SYSDATE
      AND SA_CONTR_HEAD_ID != NVL(:headId, 0)
```

<KbSubTitle>校验4：未能获取合同保证金标准，不能创建合同 —— 保证金配置缺失</KbSubTitle>

- 第1点：查询CM_DEPOSITS_PAY_STANDARD表获取标准金额
- 第2点：若查询结果为空，阻断保存

<KbTip>阻断性报错</KbTip>

```sql
SELECT * FROM CM_DEPOSITS_PAY_STANDARD WHERE ENTID = :entid AND CONTRACT_TYPE = :contractType
```

<KbSubTitle>校验5：新开发网点月度明细之和必须等于新开发网点个数 —— 任务拆分完整性</KbSubTitle>

- 第1点：仅当事业部为101或102且合同类型为8或20时校验
- 第2点：sum(1月~12月任务数) = NEW_OUTLETS_TASK

<KbTip>阻断性报错</KbTip>

```sql
SELECT 
      h.NEW_OUTLETS_TASK,
      NVL(s.JAN_TASK,0)+NVL(s.FEB_TASK,0)+NVL(s.MAR_TASK,0)+NVL(s.APR_TASK,0)+
      NVL(s.MAY_TASK,0)+NVL(s.JUN_TASK,0)+NVL(s.JUL_TASK,0)+NVL(s.AUG_TASK,0)+
      NVL(s.SEP_TASK,0)+NVL(s.OCT_TASK,0)+NVL(s.NOV_TASK,0)+NVL(s.DEC_TASK,0) AS TASK_SUM
    FROM SA_SALE_CONTRACT_HEAD h
    LEFT JOIN SALE_CONTRACT_TASK_SPLIT s ON s.HEAD_ID = h.SA_CONTR_HEAD_ID
    WHERE h.SA_CONTR_HEAD_ID = :headId
```
