# 状态流转

## 单据状态流转

```
新建 ──提交──> 已提交(RUN) ──审批通过──> 审批通过(APPROVED)
                  │                        │
                  │                        └──> 更新出库单行核销数量
                  │                             更新明细状态为valid
                  │                             计算返点
                  │
                  └──审批拒绝──> 审批拒绝(REJECTED)

任意状态 ──取消──> 核销明细状态变为CANCELED，回退出库单行数量
新建 ──删除──> 物理删除所有数据
```

## 核销明细状态流转

```
invalid(未生效) ──审批通过──> valid(已生效)
invalid/valid ──取消──> CANCELED(已取消)
```

## 出库单行核销数量变化

| 操作 | CAN_VERIFY_NUM | USED_VERIFY_NUM |
|------|---------------|-----------------|
| 审批通过 | - 本次核销数量 | + 本次核销数量 |
| 取消核销 | + 取消数量 | - 取消数量 |

## 核销头审核状态对照

| auditStat 值 | hzApproveStatus 值 | 含义 |
|--------------|---------------------|------|
| 新建 | — | 刚创建，未提交 |
| 已提交 | RUN | 审批流程运行中 |
| 审批通过 | APPROVED | 审批已通过 |
| 审批拒绝 | REJECTED | 审批已拒绝 |
