# 关联模块

## 上游依赖模块

| 模块 | 关联方式 | 说明 |
|------|---------|------|
| 发票上传与审批 | 数据依赖 | 核销可选发票来源于 `EPM_UPLOAD_INVOICE_VERIFER`，需发票上传审批通过后才能核销 |
| 出库单管理 | 数据依赖 | 核销可选出库单来源于 `INV_OUT_BILL_HEAD/LINE`，出库单签收确认后才能核销 |
| 项目管理 | 数据依赖 | 核销头关联项目信息（projectCode/projectId） |
| 合同管理 | 数据依赖 | 核销头关联合同信息（contractCode/contractId） |
| 经销商管理 | 数据依赖 | 核销头关联经销商信息（customerId） |
| 交易公司管理 | 数据依赖 | 核销头关联交易公司信息（tradingCompanyId） |
| 开票单位管理 | 数据依赖 | 核销头关联开票单位信息（billingUnitId） |
| 系统参数管理 | 配置依赖 | 核销截止日、延期天数等参数来源于 `SYS_PARAM` |
| 折扣政策 | 配置依赖 | 核销头关联折扣政策信息 |

## 下游影响模块

| 模块 | 关联方式 | 说明 |
|------|---------|------|
| 出库单核销数量 | 数据更新 | 审批通过后更新出库单行 CAN_VERIFY_NUM / USED_VERIFY_NUM |
| 渠道提价返点 | 业务触发 | 有渠道提价的出库单行审批通过后计算返点 |
| 工作流引擎 | 流程依赖 | 提交审批通过 HZERO 工作流引擎处理 |

## 核销延期关联

| 模块 | 关联方式 | 说明 |
|------|---------|------|
| 核销延期配置（EPM_INVOICE_DEALY） | 配置依赖 | 出库单存在延期配置时，核销截止日取延期配置值 |
