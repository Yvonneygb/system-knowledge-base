<KbCard title="3.2 审批操作逻辑"><p>#### 3.2.1 档案审批（archivesAudit）</p>
<p>1. 查看待审批讲师档案的详细信息（个人档案+讲师档案） 2. 审批人审核档案信息的完整性和合理性 3. 执行审批：</p>
<ul><li>通过 → 调用 <code>mlt/maLecturerApproval/archivesAudit</code>，传入审批结果=通过</li><li>拒绝 → 调用 <code>mlt/maLecturerApproval/archivesAudit</code>，传入审批结果=拒绝+审批意见</li></ul>
<p>4. 审批结果回写：</p>
<ul><li>通过 → 讲师档案状态更新为"生效"</li><li>拒绝 → 讲师档案状态更新为"审批拒绝"</li></ul>
<p>#### 3.2.2 价格审批（priceAudit）</p>
<p>1. 查看待审批讲师的价格信息 2. 审批人审核价格的合理性 3. 执行审批：</p>
<ul><li>通过 → 调用 <code>mlt/maLecturerApproval/priceAudit</code>，传入审批结果=通过</li><li>拒绝 → 调用 <code>mlt/maLecturerApproval/priceAudit</code>，传入审批结果=拒绝+审批意见</li></ul>
<p>4. 审批结果回写：</p>
<ul><li>通过 → 讲师价格生效</li><li>拒绝 → 价格维持原值</li></ul>
<p>#### 3.2.3 价格变更审批（priceChangeApproval）</p>
<p>1. 查看待审批讲师的价格变更信息（原价格、新价格、变更原因） 2. 审批人审核价格变更的合理性 3. 执行审批：</p>
<ul><li>通过 → 调用 <code>mlt/maLecturerApproval/priceChangeApproval</code>，传入审批结果=通过</li><li>拒绝 → 调用 <code>mlt/maLecturerApproval/priceChangeApproval</code>，传入审批结果=拒绝+审批意见</li></ul>
<p>4. 审批结果回写：</p>
<ul><li>通过 → 讲师价格更新为新价格</li><li>拒绝 → 价格维持原值不变</li></ul></KbCard>

<KbCard title="常见问题FAQ"><p><strong>Q1: 档案审批、价格审批、价格变更审批有什么区别？</strong></p>
<p>A: 档案审批是对讲师档案基本信息的审批；价格审批是对讲师首次设定价格的审批；价格变更审批是对讲师价格变更的审批。三者审批接口不同，回写逻辑也不同。</p>
<p><strong>Q2: 审批拒绝后能否重新提交？</strong></p>
<p>A: 可以。审批拒绝后，讲师档案状态回退，用户可在讲师档案菜单修改后重新提交审批。</p>
<p><strong>Q3: 审批通过后能否撤销？</strong></p>
<p>A: 审批通过后不支持撤销，如需变更需走变更审批流程。</p>
<p><strong>Q4: 价格变更审批中原价格和新价格如何记录？</strong></p>
<p>A: 提交价格变更时，系统自动记录原价格（original_price）和新价格（new_price），审批人可对比查看。</p>
<p><strong>Q5: 一个审批单能否多次审批？</strong></p>
<p>A: 不可以。每个审批单仅可审批一次，审批后状态终态化。</p></KbCard>
