<KbCard num="1" title="重点逻辑1：资金池来源类型联动 核心逻辑">
<KbQuote>头部的资金池来源类型变更时，所有明细行的资金池来源类型需同步更新</KbQuote>

**具体逻辑**：

- 1、前端headDS中capitalType字段的update事件，同步更新所有行记录的capitalType
- 2、行上的capitalType字段来源于头，保持一致
</KbCard>

<KbCard num="2" title="重点逻辑2：来源单据类型与来源单号联动 核心逻辑">
<KbQuote>选择来源单据类型后，来源单号LOV弹窗的查询条件随类型变化</KbQuote>

**具体逻辑**：

- 1、sourceBillType选择后，sourceBillNoObj的LOV才可用(disabled条件控制)
- 2、sourceBillType为空时，来源单号不可选择
- 3、非新建/拒绝/撤回状态下，来源单据类型不可修改
</KbCard>

<KbCard num="3" title="重点逻辑3：编码规则生成 核心逻辑">
<KbQuote>补贴单号按事业部编码+编码规则自动生成，确保唯一性</KbQuote>

**具体逻辑**：

- 1、新建时调用generateCode，基于事业部编码+编码规则AE.POLICY_SPECIAL_HEADER_NO生成
- 2、单号生成后不可修改
</KbCard>

<KbCard num="4" title="重点逻辑4：OA审批与工作流双轨审批 特殊逻辑">
<KbQuote>补贴申请同时走工作流审批和OA审批两条审批路径</KbQuote>

**具体逻辑**：

- 1、工作流编码SA_POLICY_SPECIAL_MCS_AW，完成时更新hzApproveStatus
- 2、OA送签(doOaAudit)封装头行+附件数据推送OA，更新auditStat为"已送签OA"
- 3、OA审批回调(doProcessOA)中，同意且最终审批人时更新审批金额(approvedAmt)和callbackSource
</KbCard>

<KbCard title="状态机">
### 状态机

<KbSubTitle>状态机流转图</KbSubTitle>


```text
NEW(新建) ──保存并提交──→ RUN(审批中) ──审批通过──→ APPROVED(已审批)
  ↑                         │
  │                         ├──审批拒绝──→ REJECTED(已拒绝) ──修改后保存并提交──→ RUN
  │                         └──终止──────→ INTERRUPT(已终止)
  │
  └──删除──→ (删除)

NEW/RUN ──撤回──→ WITHDRAW(已撤回) ──保存并提交──→ RUN
```

<KbSubTitle>状态机列表</KbSubTitle>


| 状态机名称 | 状态释义 | 可执行的操作 |
|-----------|---------|------------|
| NEW | 新建 | 编辑、保存、保存并提交、删除 |
| RUN | 审批中 | 无(等待审批结果) |
| APPROVED | 审批通过 | 无(流程结束) |
| REJECTED | 审批拒绝 | 编辑、保存、保存并提交 |
| WITHDRAW | 已撤回 | 编辑、保存、保存并提交 |
| INTERRUPT | 已终止 | 无(流程结束) |
