<KbQuote>报销明细可来源于出库单、退库单、历史签收或虚拟调账</KbQuote>

**具体逻辑**：

### 状态机

<KbSubTitle>状态机流转图</KbSubTitle>


```text
新建(0) → 制单(1) → 已提交(-1) → 审核通过(5)
                ↑                ↓
                └──── 可删除 ←───┘(审批拒绝后)
                                      ↓
                              推送2FSCC → FSCC审批通过(已核销) / FSCC拒绝
```

<KbSubTitle>状态机列表</KbSubTitle>


| 状态机名称 | 状态释义 | 可执行的操作 |
|-----------|---------|------------|
| 0 | 新建 | 保存 |
| 1 | 制单 | 保存、修改、删除、提交 |
| -1 | 已提交 | 等待审批 |
| 5 | 审核通过 | 不可编辑、不可删除，已推送FSCC |
