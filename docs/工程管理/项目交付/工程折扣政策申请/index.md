<KbCard num="1" title="重点逻辑1：工程/家装/样品三菜单共用后端代码 共用代码">
<KbQuote>工程折扣政策申请、家装折扣政策申请、样品折扣政策申请共用同一套后端代码，通过isMakt和suitableType区分</KbQuote>

**具体逻辑**：

- 1、工程isMakt=0, suitableType=normal；家装isMakt=0, suitableType=normal(通过事业部区分)；样品isMakt=2, suitableType=special
- 2、编码规则根据suitableType和isMakt选择——工程用AE.EPM_DISCOUNT_POLICY_GC、家装用AE.EPM_DISCOUNT_POLICY_JZ、样品用AE.EPM_DISCOUNT_POLICY
- 3、审批通过后，通用折扣(suitableType=normal)直接生效(valid=2)，专项折扣(suitableType=special)需同步CRM
</KbCard>

<KbCard num="2" title="重点逻辑2：保存前预校验 核心逻辑">
<KbQuote>保存时执行多项业务校验，确保政策数据完整性和合规性</KbQuote>

**具体逻辑**：

- 1、校验产品行(checkProductLine)——确保至少有一条产品明细行
- 2、校验申请类型(checkApplicationType)——确保产品行的申请类型合法
- 3、校验优惠方式(checkPreferentialType)——确保产品行的优惠方式(折扣/特价)合法
- 4、必填字段校验(requiredField)——确保头信息关键字段已填写
</KbCard>

<KbCard num="3" title="重点逻辑3：审批通过后生效逻辑 核心逻辑">
<KbQuote>审批通过是政策生效的必要条件，不同类型政策生效方式不同</KbQuote>

**具体逻辑**：

- 1、通用折扣(suitableType=normal)审批通过后直接设valid=2(有效)，无需推送CRM
- 2、专项折扣(suitableType=special)审批通过后调用CRM接口创建折扣政策，CRM返回crmid/crmcode后设valid=2
- 3、审批拒绝/终止时更新hzApproveStatus，不改变valid状态
</KbCard>

<KbCard title="导入">
<KbSubTitle>前置约定</KbSubTitle>


- 支持产品明细和阶梯政策Excel导入(importProduct)
- 文件格式：Excel(.xlsx)


<KbSubTitle>字段映射</KbSubTitle>


| 字段含义 | 是否必输 | 字段格式 | 重复判定字段 |
|---------|---------|---------|------------|
| 产品编码 | 是 | 文本 | ITEM_CODE |
| 申请类型 | 是 | 数值(1/2/3) | - |
| 优惠方式 | 是 | 数值(1/2) | - |
| 折扣率/特价 | 是 | 数值 | - |


<KbSubTitle>处理逻辑</KbSubTitle>


- **校验逻辑**：产品编码必须存在且有效；申请类型和优惠方式必须合法
- **导入逻辑**：根据申请类型分别处理，自动匹配产品价格信息
- **重复处理策略**：产品编码重复时覆盖
- **性能方案**：同步处理


<KbSubTitle>异常与结果约定</KbSubTitle>


- 部分成功/失败时：整批回滚
- 结果反馈机制：导入失败明细提示


<KbSubTitle>运维保障</KbSubTitle>


- 日志记录：标准日志
- 断点续传/重试机制：不支持


</KbCard>

<KbCard title="状态机">
### 状态机

<KbSubTitle>状态机流转图</KbSubTitle>


```text
NEW(新建) ──保存并提交──→ RUN(审批中) ──审批通过──→ APPROVED(已审批) → 通用折扣直接生效/专项折扣同步CRM
  ↑                         │
  │                         ├──审批拒绝──→ REJECTED(已拒绝) ──修改后保存并提交──→ RUN
  │                         ├──审批驳回──→ REBUT(已驳回)
  │                         └──终止──────→ INTERRUPT(已终止)
  │
  └──删除──→ (删除)
```

<KbSubTitle>状态机列表</KbSubTitle>


| 状态机名称 | 状态释义 | 可执行的操作 |
|-----------|---------|------------|
| NEW | 新建 | 编辑、保存、保存并提交、删除 |
| RUN | 审批中 | 无(等待审批结果) |
| APPROVED | 审批通过 | 无(流程结束，政策已生效) |
| REJECTED | 审批拒绝 | 编辑、保存、保存并提交 |
| WITHDRAW | 已撤回 | 编辑、保存、保存并提交 |
| INTERRUPT | 已终止 | 无(流程结束) |
